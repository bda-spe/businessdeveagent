Build a full-stack SaaS web app for a white-label AI estimating platform for local service businesses. The UI should match this style: clean white background, navy accents, simple cards, soft borders, lots of spacing, professional B2B SaaS look, not flashy or overly “tech startup.” Use placeholder branding only: “Logo” or “AI Estimator Platform.” Do not invent a final product name.

Core concept:
Businesses create an account, onboard their company data, upload documents, review extracted requirements, test their AI estimating agent in a sandbox, choose a billing plan, and then receive an embeddable website widget. The platform uses one central OpenAI integration, but each business has its own profile, pricing, services, rules, documents, leads, and widget.

Tech requirements:
- Full-stack app with React/Next.js-style frontend
- PostgreSQL database
- Authentication with email/password
- Multi-tenant structure using client_id/business_id
- File upload support
- Stripe billing integration placeholder
- OpenAI integration placeholder using environment variable OPENAI_API_KEY
- Gmail SMTP/app password email setup using environment variables:
  - GMAIL_USER
  - GMAIL_APP_PASSWORD
- Send welcome email after signup/onboarding completion
- Generate embeddable widget script per client

AI workflow:
When a widget or sandbox request comes in:
1. Use client_id to fetch the correct business profile
2. Fetch services, pricing rules, uploaded document summaries, approved requirement values, and sandbox notes
3. Build a structured prompt for OpenAI
4. Ask OpenAI to return JSON with:
   - customer_summary
   - assumptions
   - recommended_price_range
   - invoice_line_items
   - total_estimate
   - confidence_score
   - follow_up_questions
5. Save the result as an estimate/lead
6. Display it in the dashboard and lead inbox
