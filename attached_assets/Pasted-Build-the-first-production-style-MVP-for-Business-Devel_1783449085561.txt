Build the first production-style MVP for Business Development Agent (BDA) by Sean Pelillo Enterprises.

Branding:
- The customer-facing product name is “Business Development Agent”
- The acronym is “BDA”
- Do not prominently display “Sean Pelillo Enterprises” in the app UI
- Sean Pelillo Enterprises may appear only in footer/legal/T&Cs areas
- Do not call the product QuoteCraft, QuoteBuilder, AI Estimator Platform, or invent another name

Core concept:
Business Development Agent is a multi-tenant SaaS platform that lets local service businesses create, train, test, and deploy their own AI-powered business development agent. A BDA acts like a digital employee that can answer customer questions, qualify leads, generate estimates, draft invoices, and store lead activity.

Important architecture:
- Use one centralized OpenAI integration through the existing Replit secret:
  OPENAI_API_KEY
- Do not ask for a new API key
- Do not expose the API key in frontend code
- All OpenAI calls must happen server-side only
- Each client/business gets a unique client_id and business profile
- The same OpenAI key powers every client, but each response must be customized using that business’s services, pricing rules, requirements, uploaded documents, sandbox feedback, and widget settings

Tech requirements:
- Full-stack web app
- Clean React/Next.js-style frontend
- PostgreSQL database
- Email/password authentication
- Multi-tenant database structure using business_id/client_id
- File upload support
- Stripe billing placeholder
- Gmail SMTP welcome email using:
  GMAIL_USER
  GMAIL_APP_PASSWORD
- Centralized AI service file, such as /server/aiService.ts or /lib/aiService.ts
- All AI functions should live in that service:
  extractBusinessKnowledge()
  evaluateRequirements()
  generateEstimate()
  generateInvoice()
  runSandboxTest()
  summarizeLead()

AI workflow:
When a sandbox or widget request comes in:
1. Use client_id/business_id to fetch the right business
2. Load services, pricing, requirements, uploaded document summaries, sandbox notes, and widget settings
3. Build a structured prompt
4. Call OpenAI using process.env.OPENAI_API_KEY server-side
5. Request JSON output with:
   customer_summary
   assumptions
   recommended_price_range
   invoice_line_items
   subtotal
   taxes
   total_estimate
   confidence_score
   follow_up_questions
6. Save the result to estimates/leads
7. Display it in the dashboard and Lead Inbox
